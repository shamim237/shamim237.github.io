# Shamim Mahbub Portfolio

Personal portfolio website built with React and Vite.

## Overview

This project contains my portfolio website, including sections for projects, skills, about, contact, and a downloadable resume.

Resume file used in the site:

- `public/Shamim_Mahbub_Resume_GenAI.pdf`

## Tech Stack

- React
- Vite
- Tailwind CSS
- Motion

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

Then open:

- `http://localhost:5173`

## Build for Production

```bash
npm run build
```

The production output is generated in:

- `dist/`

## Deploy Notes (GitHub Pages)

- Deploy the built `dist/` files (not raw source files).
- If you update site content, rebuild and redeploy.

## Customize

Common updates you can make:

- Profile text and sections in `src/app/components/`
- Navigation links in `src/app/components/Navigation.tsx`
- Browser tab title in `index.html`
- Resume file in `public/`
